
# UniTextExtension
An extension for the text engine that includes the creation of objects with the [UniText](https://github.com/LightSideKittens/UniText) component and the automatic implementation of localization from Unity.
## Features
 1. You can easily create objects using UniText components, which is not
    available in the open version.

	Just use the path in the object creation context menu: `UI (Canvas)/UniText`
	
 2. You can localize UniText for Unity Localization, just like in TextMeshPro.

	Just use the method in the UniText component’s context menu: `Localize`

## Installation

If you don’t have UniText installed, be sure to install it first.

1.  Open **Window > Package Manager**
2.  Click **+** > **Add package from git URL...**
3.  Enter:
    
    ```
    https://github.com/LightSideMeowshop/unitext.git#1.0.0
    ```
 If UniText is installed, install the UniTextExtension package.
 
1.  Open **Window > Package Manager**
2.  Click **+** > **Add package from git URL...**
3.  Enter:
    
    ```
    https://github.com/AndiSeko/UniTextExtension.git
    ```
